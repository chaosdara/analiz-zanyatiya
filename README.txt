ПРИЛОЖЕНИЕ «АНАЛИЗ ЗАНЯТИЯ» — сборка APK за 15 минут (без программирования)

СОСТАВ ПАКЕТА
  index.html          — страница «Бланк анализа» (точная копия бланка из Приложения 1)
  spravochniki.html   — страница «Справочники» (8 списков с возможностью правки)
  manifest.json       — описание приложения
  service-worker.js   — офлайн-режим (работа без интернета)
  icon-192.png, icon-512.png — иконка приложения

ЧТО УМЕЕТ ПРИЛОЖЕНИЕ
  • Бланк по образцу: шапка, таблица требований (23 строки, оценки Хор./Удовл./Неуд. тапами),
    выводы, подписи. Автосохранение, кнопки «Печать / PDF» и «Очистить».
  • Справочники: Форма занятия, Тип занятия, Цель посещения (80), Выводы (48),
    Рекомендации (25) — стандартные из методических рекомендаций; Группы, Учебные
    дисциплины, Преподаватели — заполняются вами.
  • Правка справочников: кнопка ✎ — изменить пункт, ✕ — удалить, «＋ Добавить» — новый,
    «↺ Стандарт» — вернуть исходный список.
  • Подсказки при заполнении: поля «Группа», «Учебная дисциплина», «ФИО преподавателя»
    предлагают варианты из ваших справочников.
  • Печать в PDF: имя файла подставляется автоматически —
    Взаимопосещения_Анализ_дата_ФИО. Сохраняйте в папку «Взаимопосещения».

ШАГ 1. Разместите файлы на бесплатном HTTPS-хостинге (GitHub Pages)
  1. Зарегистрируйтесь на github.com (если аккаунта ещё нет).
  2. Создайте новый репозиторий (кнопка New repository), имя например: analiz-zanyatiya.
     Поставьте галочку Public.
  3. Откройте репозиторий → Add file → Upload files → загрузите ВСЕ файлы из этого пакета
     (index.html, spravochniki.html, manifest.json, service-worker.js, обе иконки).
  4. Нажмите Commit changes.
  5. В репозитории: Settings → Pages (слева) → Source: Deploy from a branch →
     Branch: main, папка /(root) → Save.
  6. Через 1–2 минуты страница будет доступна по адресу:
     https://ВАШ_ЛОГИН.github.io/analiz-zanyatiya/
     Проверьте с телефона: откройте адрес, бланк должен работать.

ШАГ 2. Соберите APK через PWABuilder (бесплатный сервис Microsoft)
  1. Откройте https://www.pwabuilder.com
  2. Вставьте адрес вашей страницы → Start.
  3. Дождитесь анализа (страница должна получить «зелёный» рейтинг; если пункты о
     manifest/иконках отмечены — всё в порядке).
  4. Package for stores → Android → Generate.
  5. Скачайте ZIP: внутри папка с готовым подписанным APK (app-release-signed.apk).
     Вариант «Legacy/Bubblewrap» тоже подходит — берите первый предложенный.

ШАГ 3. Установите на телефон
  1. Скиньте APK на телефон (или скачайте прямо с телефона по ссылке).
  2. Откройте файл — Android спросит разрешение «устанавливать из неизвестных
     источников» — разрешите (это безопасно: APK собран с вашего сайта).
  3. Установите. На рабочем столе появится иконка «Анализ занятия».

ЗАПАСНОЙ ВАРИАНТ (если PWABuilder недоступен)
  https://appsgeyser.com — вставьте ссылку на страницу, получите APK за 10 минут.
  Минус: в бесплатной версии внутри приложения показывается реклама сервиса.

ЗАМЕЧАНИЯ
  • Данные (бланки и правки справочников) хранятся в памяти каждого телефона.
    Если правки справочников должны быть общими — внесите их один раз в код
    index.html и spravochniki.html (списки DEFAULTS в начале скрипта) и загрузите
    обновлённый файл на GitHub Pages.
  • После изменения файлов на хостинге приложение обновится при следующем
    запуске с интернетом (service-worker подхватит новую версию).
